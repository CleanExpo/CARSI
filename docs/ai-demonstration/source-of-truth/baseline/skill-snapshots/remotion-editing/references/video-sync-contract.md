# Narrated software demonstration standard

When creating, editing, rendering or reviewing a narrated software demonstration, read `~/.unite-group/video-sync/VIDEO-SYNC-RULE.md`, `APPROVED-BASELINE.md` and `approved-baseline.json` in that directory before work. The owner-approved baseline is a minimum, not permission to skip the executable evidence gate or publish. If these files are unavailable, recover the shared package from the owning job before claiming readiness. Confirm the baseline SHA and record a parent SHA for client derivatives.
