## 4. Course summary and learning objectives

**Summary.** This course covers the advanced drying equipment and methods used in complex structural drying projects, including desiccant dehumidification systems, the mechanical elements of drying plant, air treatment technologies, monitoring equipment, and software tools for drying project management. It is designed for technicians who need to operate, select, and manage advanced equipment on commercial, large loss, and specialty drying projects. Aligned with the IICRC S500 standard and Australian equipment safety requirements.

**Learning objectives / curriculum outline.**

- MODULE 1: Desiccant Systems
- MODULE 2: Mechanical Drying Elements
- MODULE 3: Air Treatment Technologies
- MODULE 4: Monitoring Equipment
- MODULE 5: Software Tools
- WHAT YOU WILL LEARN
- MODULE 6: Equipment Selection for Complex Projects
- MODULE 7: System Integration and Drying Strategy
- What you learnt
