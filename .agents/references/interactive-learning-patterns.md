# Interactive learning patterns

CARSI must not be “video + paragraph + quiz only.” For each lesson, ask whether interaction teaches better.

## Patterns

1. **Scenario-based learning** — realistic job decisions (e.g. first action after a water loss).
2. **Interactive diagrams** — equipment, damage zones, process steps (use approved media/diagrams — see course diagram guards).
3. **Knowledge challenges** — short questions with explained feedback, not punitive guessing.
4. **Practical simulations** — evidence + decision + consequence feedback.

## Educational integrity (non-negotiable)

- No fabricated IICRC requirements or invented technical guidance.
- Do not change approved course content without validation and evidence ledger rules.
- Run IICRC/CEC checks when touching course copy: `npm run check:iicrc-terminology`, related scripts in `package.json`.
- Legacy production depth: `.claude/skills/carsi-course-production/SKILL.md`.

## UX bar

- Mobile-first lesson reading
- Clear outcomes and milestones
- Feedback explains *why*, not only right/wrong
- Prefer one strong interaction over decorative animation
