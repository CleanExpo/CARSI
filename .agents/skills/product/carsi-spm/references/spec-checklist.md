# SPM spec checklist (CARSI)

Read-only spec before build. Output under `docs/specs/` unless the user assigns another path.

## Required sections

1. **Outcome** — restoration professional value + business metric
2. **Surface** — marketing (A) / learning (B) / admin (C) per `visual-surfaces.md`
3. **Scope** — files and routes touched; no drive-by refactors
4. **Media plan** — sources, `media.manifest.json` entries, budgets
5. **Dependencies** — only with `approved-libraries.md` justification
6. **Risks** — auth, commerce, IICRC copy, accessibility
7. **Verification** — commands from `quality-gates.md` + SDA evidence if customer-facing

## Hold criteria

- Missing media provenance on new public assets
- No verification plan
- Unresolved conflict with `docs/agents/AGENTS.md` or `CLAUDE.md`
