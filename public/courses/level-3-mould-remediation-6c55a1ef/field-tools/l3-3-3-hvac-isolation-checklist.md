# HVAC isolation and inspection checklist

CARSI · Level 3 Mould Remediation · Lesson 3.3 · Field download

Australian-produced. Metric units. Use on site, then file it in the job record.

Job address: ______________________   Date: ____/____/______   Supervisor: ______________________

- [ ] System serving the affected area identified on the building plan: unit, supply, return, plenum, zones served.
- [ ] System turned off with the building manager, tagged out, time recorded.
- [ ] Supply and return grilles in the work area sealed with film. HVAC never used to dry the work area.
- [ ] Condensate tray and drain inspected: water, slime, growth, blockage. Photos.
- [ ] Filters inspected: loading, wetness, growth. Photos. Bagged as waste if removed.
- [ ] Duct behind the nearest grilles inspected: sheet metal, internally lined or flexible.
- [ ] Findings sent to the building manager and the HVAC contractor (and hygienist, if engaged).
- [ ] Duct and unit cleaning or replacement scoped in writing by the specialist contractor.
- [ ] Refrigerant and electrical work only by licensed trades.
- [ ] Restart only after sign-off by a qualified person. Name, date, time: recorded.
