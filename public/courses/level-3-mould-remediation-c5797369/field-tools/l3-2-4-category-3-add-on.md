# Category 3 and sewage add-on checklist

CARSI · Level 3 Mould Remediation · Lesson 2.4 · Field download

- [ ] Water source recorded: floodwater, sewage, toilet overflow. Depth (m) and how long it stood.
- [ ] Risk assessment uses the biological hazards Code where approved. SWMS updated.
- [ ] Crew vaccination discussed (the Immunisation Handbook recommends hepatitis A vaccine for plumbers and sewage workers). Record kept.
- [ ] Hygiene set up: no eating, drinking or smoking in work areas, wash facilities, cuts covered, clothes bagged before leaving site.
- [ ] PPE: fluid-resistant coveralls, puncture-resistant gloves, eye protection, respiratory protection per the SWMS.
- [ ] Soaked porous materials listed for removal: carpet, underlay, plasterboard to above the water and growth lines, insulation, particleboard.
- [ ] Contents: inventory, condition, owner's written consent before disposal.
- [ ] Order: remove, then clean and sanitise, then dry, then finish mould work. No air movers before removal.
- [ ] Infection control lead involved for healthcare or aged care premises.
