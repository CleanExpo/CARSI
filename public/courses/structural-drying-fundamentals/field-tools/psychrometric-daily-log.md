# Psychrometric daily log

**CARSI Structural Drying Practitioner — field tool (Module 2)**
*DRAFT v1 for SME review. Australian and New Zealand job conditions: 230 V / 50 Hz, 10 A GPO, metric units.*

Log **g/kg** at the same five points, in the same order, every visit. RH alone cannot prove drying, because it changes with temperature.

## Condensation check

| Surface | Surface °C | Room dew point °C | Below dew point? | Action |
| --- | --- | --- | --- | --- |
| Slab | | | Yes / No | |
| External wall | | | Yes / No | |

Air cooled to its dew point condenses. If a surface is below the room dew point, lower the room g/kg, warm the surface, or both, before trusting readings there.

*Units: g/kg = grams of water per kilogram of dry air. Imported gear may show grains per pound: 1 g/kg = 7 gr/lb.*
