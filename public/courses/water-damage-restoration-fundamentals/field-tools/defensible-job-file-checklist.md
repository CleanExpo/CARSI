# Defensible job-file checklist

**CARSI Water Restoration Practitioner — field tool (Module 6)**
*DRAFT v1 for SME review. Australian-produced: metric, AUD, AS/NZS / Safe Work Australia framing.*

**Build the file as the job happens — records made at the time are what an assessor or court accepts.**

## First attendance

- [ ] Cause of loss, **category** and **class**, with reasons
- [ ] Date and time of attendance
- [ ] Affected floor area in **m²**
- [ ] Photographs: affected areas, the source, the damage (captioned with what and where)

## Assessment and plan

- [ ] Moisture map with numbered points, materials, instruments
- [ ] **Dry standard** recorded and the **dry goal** set from it
- [ ] Drying plan: equipment placed, where and why, with the **230 V / 10 A** power arrangement

## Daily monitoring (each visit)

| Day | Air (°C) | RH (%RH) | Zone g/kg | Material readings → dry goal |
| --- | --- | --- | --- | --- |
| | | | | |

- [ ] Readings trending to the dry standard (measured evidence drying is working)

## Safety

- [ ] Hazards identified, controls applied, **PPE actually used**
- [ ] Any specialist called (electrician, engineer, 13 11 26, 000)

## Decisions and authorities

- [ ] What was restored, what was removed and **why**
- [ ] Who authorised each scope change (before acting, in writing)

## Insurance context

- [ ] Work to an **agreed scope**; changes authorised and recorded
- [ ] Pricing in **AUD**, GST noted where it applies
- [ ] **No over-claiming** — no "sterilised", no guaranteed fixed dry time (Australian Consumer Law: due care and skill)
- [ ] Plain-English explanation given to the occupant
