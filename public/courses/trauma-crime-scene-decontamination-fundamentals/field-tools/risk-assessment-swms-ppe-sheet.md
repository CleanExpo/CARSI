## 4. PPE set and fit

- Fluid-resistant disposable coveralls with hood · boot covers or washable boots · eye protection or face shield
- Disposable nitrile gloves (double); occupational gloves to AS/NZS 2161.10 where required
- Respirator to AS/NZS 1716, fit-tested before first use and fit-checked each time it goes on

| Worker | Respirator make / model / size | Fit test date | Clean-shaven at seal? |
| --- | --- | --- | --- |
| | | | |

**On (clean zone):** hand hygiene → coveralls → boot covers → respirator + fit check → eye protection → hood → inner gloves → outer gloves.

**Off (transition zone):** outer gloves → coverall (roll outwards) → boot covers → inner gloves → hand hygiene → eye protection → respirator → hand hygiene.

**Stop and escalate** when a hazard cannot be controlled: supervisor, licensed electrician, licensed asbestos assessor, **000** (AU) or **111** (NZ).

**Asbestos before you cut:** in Australia, assume asbestos may be present in any building built or renovated before 31 December 2003, when the national ban took effect; buildings built or renovated before 1990 are the most likely to contain it. In New Zealand, any building built or renovated before 2000 could contain asbestos (WorkSafe NZ).
