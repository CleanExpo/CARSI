# Practical submission checklist

**CARSI Mould Remediation Practitioner — field tool (Module 4)**
*DRAFT v1 for SME review. Five criteria x 20 points; 70 to pass. Then the final designation exam at 80%.*

| Criterion | The assessor needs to see | Done |
| --- | --- | --- |
| 1. Site reading, size and cause | Every patch measured and **totalled** in m²; size band named; cause and fix; moisture map from a **dry reference** with instrument and mode; air in °C, %RH, g/kg and dew point; **asbestos check** if built before 1990 | |
| 2. Containment, controls and power | Containment sketch; sealed vents; volume (m³) and air changes per hour; how negative pressure was confirmed against the target your supervisor set; **amps per circuit at 230 V**, RCD, tested and tagged leads | |
| 3. PPE, people and health boundaries | Respirator type with **AS/NZS 1716** marking, **fit-test date**, fit check each wear; skin and eye protection; heat plan; sensitive occupants kept away; **no health advice** (refer to a GP) | |
| 4. Order of work, airflow and verification | Steps in order from fixing the water to rebuild; porous materials over 48 h or with growth removed (m²); waste route; no air moved across growth before containment and removal; dehumidifier **g/kg drop**; four verification checks with readings against the reference | |
| 5. Job file, communication, Australian production | File built on the day; honest gaps marked; scope change approved in writing; AUD with 10% GST; plain-English handover; Australian English, metric, 230 V; own words; standards named only | |

**Stranger test:** could someone who was not there rebuild the job from your submission? If a decision has no evidence, add it or mark the gap honestly.
