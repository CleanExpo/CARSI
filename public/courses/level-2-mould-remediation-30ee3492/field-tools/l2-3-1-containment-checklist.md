# Containment set-up and daily check

CARSI · Level 2 Mould Remediation · Lesson 3.1 · Field download

Australian-produced. Metric units. Use on site, then file it in the job record.

- [ ] Air-conditioning in the area turned off and isolated. Supply and return vents sealed.
- [ ] Gaps under doors, around pipes and power points sealed with film and tape.
- [ ] Frame stable, film walls taped at floor, walls and ceiling with no gaps.
- [ ] Entry flap or zip door working. Airlock built where workers remove outer PPE.
- [ ] Floor protection laid along the clean path to the exit.
- [ ] Signage at the entry: authorised entry only, respiratory protection required.
- [ ] Start of each shift: walls draw inwards, all seams intact, airlock clean.
- [ ] Manometer reading logged each shift (−5 Pa or more negative). Breach or lost pressure: stop work. Fix it and re-test, then log and report it.
- [ ] Record each check with the time and your initials.
