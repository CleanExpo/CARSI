# PPE and respirator checklist

CARSI · Level 2 Mould Remediation · Lesson 3.3 · Field download

Australian-produced. Metric units. Use on site, then file it in the job record.

- [ ] Respirator type set in the SWMS for this job: P2 disposable, half-face P2, full-face P3 or powered.
- [ ] Each wearer fit tested on this exact respirator model and size. Date of test recorded.
- [ ] Clean-shaven where the respirator seals, or a loose-fitting powered respirator issued.
- [ ] Fit check done each time the respirator is put on.
- [ ] Coveralls with hood, nitrile gloves, eye protection, overshoes: quantities packed.
- [ ] Don in the clean area. Doff in the airlock, outer layers first, respirator last.
- [ ] Wash hands and face after doffing. Used PPE bagged as mould waste.
- [ ] Cartridges changed per the manufacturer and when breathing becomes harder.
